# 🚇 Weather & Transit Web - Frontend Dashboard

> **상위 프로젝트 문서**: [`../../README.md`](../README.md)  
> **요구사항 명세서**: [`../../docs/REQUIREMENTS.md`](../docs/REQUIREMENTS.md)  

기상 및 교통 데이터를 기반으로 지역별 대중교통 이용 수요와 혼잡도를 예측하고 시각화하는 React/Vite 기반 웹 대시보드입니다.

---

## 📌 주요 화면 및 기능

### 1. 메인 대시보드 (`page === 'main'`)
- **실시간 기상 요약**: 기온, 강수량, 습도, 풍속 상태 표시
- **교통수단 추천 스코어**: 현재 기상 상황에 따른 최적 이동 수단(지하철/버스/따릉이) 추천 및 추천 사유 제시
- **강우량-이용객 상관관계 시각화**: 강수량 변화에 따른 교통수단별 수요 변동 추이 차트
- **행정동별 실시간 혼잡도**: 서울 주요 행정동 단위 지하철/버스/따릉이 혼잡도 게이지

### 2. 기상 맞춤형 경로 추천 (`page === 'route'`)
- **지하철역 실시간 자동완성 검색**: 출발지(`🟢 출발지`)와 도착지(`🔵 도착지`)에 수도권 전체 561개 지하철역 자동완성 검색 드롭다운 연동
- **키보드 접근성 완벽 지원**: 방향키(`↑`/`↓`), `Tab`, `Enter`로 마우스 없이 자동완성 결과 즉시 선택 및 자동 스크롤
- **최소 환승 우선(Minimum Transfer Priority) 최적 경로 탐색 엔진 (`subwayGraph.ts`)**:
  - 다익스트라 기반 가중치 탐색(`transfers * 10,000 + stops`)으로 불필요한 환승을 원천 차단하고 **환승 0회 직통 또는 최소 환승 경로를 최우선 도출**
  - 호선 간 환승 시 보행 및 대기 시간(회당 4분)을 예상 소요 시간에 정밀 반영
- **동일 호선 지선/분기역 필수 계통 환승 처리**:
  - `구일역`(경인선) ↔ `가산디지털단지역`(경부선) 등 동일 1호선 내 지선 간 이동 시 `구로역` 필수 환승을 강제 적용하여 실제 운행 체계와 100% 일치
- **실시간 열차 탑승 정보 (출발역 및 환승역 잔여 시간 카운트다운)**:
  - 출발역 탑승 열차 및 환승역 갈아탈 열차의 실시간 도착 시간(`⏱️ N분 후 도착`), 탑승 호선, 진행 방면을 카드 및 배지로 직관적 표출
- 기상 악화(우천, 강설 등) 시 교통수단별 예상 소요 시간 및 요금, 혼잡도 비교 안내
- `경로 검색 및 지도 보기` 버튼 클릭 시 선택된 경로로 지도 즉시 이동 및 전체 경로 뷰포트 맞춤

### 3. 실시간 인터랙티브 지도 (`page === 'map'`) — `TransitMap.tsx`
- **새로고침 시 탭 유지 (Tab State Persistence)**:
  - 브라우저를 새로고침(F5)해도 `지도 보기` 탭(#map) 또는 현재 활성화된 탭이 그대로 유지됨 (LocalStorage & URL Hash 동기화)
- **수도권 전체 561개 지하철역 정밀 GPS 좌표 완벽 매핑**:
  - 서울 열린데이터광장 역사마스터(`subwayStationMaster`) API 전수 검증을 거친 소수점 6자리 정밀 GPS 좌표 탑재
  - 1호선 연천 연장선(소요산 ↔ 청산 ↔ 전곡 ↔ 연천) 등 최신 개통 역을 포함한 수도권 전 노선 위상 정합성 보장
- **🎯 경로 집중 모드 (Route Focus Mode & GeoJSON 선분 시각화)**:
  - 경로 검색 시 경로에 포함되지 않은 다른 모든 역과 버스/따릉이 거점을 지도에서 일괄 숨김(`display: none`) 처리하여 이동 동선에 온전히 몰입
  - 출발역부터 도착역까지의 전체 경로를 고대비 네온 라인으로 드로잉하고, 카메라를 전체 경로가 한눈에 들어오도록 자동 조정(`map.fitBounds`)
  - 상단 닫기(`✕`) 또는 초기화 클릭 시 전체 거점 뷰로 원클릭 복원
- **출발 / 도착 / 환승 전용 고대비 핀 마커**:
  - 🟢 **출발역 (`route-start-pin`)**: 탑승 호선, 방면, 실시간 도착 시간(`⏱️ [방면] N분 후 도착`) 뱃지 표출
  - 🔴 **도착역 (`route-end-pin`)**: 도착역 강조 핀 및 혼잡도 뱃지 표출
  - 🟠 **환승역 (`route-transfer-pin`)**: 환승역 좌표에 앰버 캡슐 핀을 자동 생성하여 갈아탈 호선 및 실시간 도착 시간(`⏱️ [방면] N분 후 도착`) 직관적 표출
  - 일반 알약 마커 겹침 방지(Collision Culling)를 통해 핀 위치 마커 중복 방지
- **지도 역 마커 겹침 방지 (화면 충돌 감지 & 확대 시 순차 노출)**:
  - 축소 시 역 마커들이 서로 겹쳐서 가려지는 현상을 방지하기 위해 겹치는 구역에서는 핵심 거점 역 1개만 우선 노출
  - 지도를 확대(Zoom-in)하면 인접한 세부 역 및 정류소가 부드럽게 순차적으로 모두 나타남
  - 사용자가 검색하거나 선택한 역은 항상 최우선으로 화면에 100% 표시됨
- **키보드 단축키 지원 초고속 검색**:
  - 검색어 입력 후 `Enter` 또는 `Tab` + `Enter` 키로 원하는 역 즉시 선택
  - 선택 시 해당 역 GPS 좌표로 부드럽게 자동 카메라 이동(`flyTo`) 및 실시간 도착/혼잡도 표출
- **MapLibre GL JS & OpenStreetMap(OSM)**: 오픈소스 래스터 타일을 활용한 부드러운 3D 틸트/회전 지도 렌더링
- **실제 좌표 기반 거점 마커**:
  - 수도권 561개 지하철역 전체 마커 매핑
  - 주요 버스 환승 정류소(강남역 중앙차로, 신논현역, 여의도환승센터, 서울역버스환승센터 등)
  - 따릉이 대여소(강남역 9번출구, 여의나루역 앞, 잠실역 등)
- **AI 예측 혼잡도 동적 컬러링**:
  - 🟢 여유 (< 45%) / 🔵 보통 (45% ~ 75%) / 🔴 혼잡 (> 75%)
  - 마커 클릭 시 정류소별 노선 정보 및 기상 민감도 분석 팝업 표출
- **⚡ AI 날씨-수요 시뮬레이터**:
  - 가상 강수량 슬라이더(0.0 ~ 10.0 mm/h) 조절 시 실시간 수요 전이(따릉이 급감, 대중교통 집중) 시뮬레이션
  - 시간대별(07시~21시) 시계열 예측 필터
- **권역 원클릭 카메라 이동(FlyTo)**: 강남·역삼, 잠실·송파, 여의도, 서울역·도심
- **📡 개발자 콘솔 실시간 모니터링**:
  - 상단 `[📡 API 콘솔 로그 확인]` 버튼 클릭 시 브라우저 콘솔(`F12`)에 기상청·버스·지하철 공공 API 규격 데이터 일괄 출력

## 🛠️ 기술 스택

- **Framework**: React 19, TypeScript
- **Bundler / Dev Server**: Vite 8
- **Styling**: Tailwind CSS v4, Custom Dark Glassmorphism Theme
- **Map Engine**: MapLibre GL JS v4, OpenStreetMap (Raster Tiles)

## 🚀 실행 및 빌드 방법

### 1. 의존성 패키지 설치
```bash
npm install
```

### 2. 개발 서버 구동
```bash
npm run dev
```
- 브라우저 접속: **`http://localhost:8443/`**

### 3. 프로덕션 빌드
```bash
npm run build
```
- 빌드 결과물은 `dist/` 디렉토리에 생성됩니다.

## 📋 최근 변경 이력 (Changelog)

프론트엔드 상세 변경 이력 및 원인/해결 분석 문서는 **[`docs/CHANGELOG.md`](docs/CHANGELOG.md)**에 체계적으로 기록되어 있습니다.

- **[2026-09-27] 주요 변경 사항 요약**:
  1. **마커 호버 점프 버그 수정**: `MapLibre`의 `translate` 위치 CSS를 훼손하지 않도록 내부 뱃지(`.marker-pill`)에만 호버 스타일 격리 적용
  2. **지도 마커 겹침 방지 (Collision Detection)**: 화면 픽셀 투영 기반 실시간 충돌 감지로 겹치는 역은 1개만 우선 노출, 확대 시 순차적 자동 노출
  3. **지하철역 정밀 GPS 좌표 전수 갱신**: 서울 열린데이터광장 역사마스터 784개 역사 데이터를 연동하여 561개 전체 역 소수점 6자리 정밀 좌표 매핑 완료
  4. **새로고침 시 탭 유지 (Tab State Persistence)**: `localStorage` 및 `window.location.hash` 연동으로 F5 새로고침 시에도 활성 탭 유지
  5. **검색창 키보드 접근성 완벽 지원**: `Enter`, `Tab` + `Enter`, `방향키(↑/↓)` 조작 및 자동 스크롤 연동
  6. **🎯 경로 집중 모드 및 GeoJSON 경로선 렌더링**: 경로 검색 시 경로에 포함되지 않은 역 일괄 숨김, 자동 뷰포트 맞춤(`fitBounds`) 및 복원 지원
  7. **⚡ 최소 환승 우선(Minimum Transfer Priority) 알고리즘 도입**: 다익스트라 기반 가중치로 환승 0회 직통 또는 최소 환승 경로 최우선 보장
  8. **⏱️ 출발역 및 환승역 탑승 열차 실시간 잔여 시간 안내 연동**: 출발역(초록) 및 환승역(앰버) 전용 핀, 상단 플로팅 카드, 사이드바 실시간 카운트다운(`⏱️ [방면] N분 후 도착`) 표출
  9. **🚇 1호선 노선 인접 그래프 위상(Topology) 결함 수정**: 인천역 ↔ 청산역 오연결 해제, 소요산 ↔ 청산 ↔ 전곡 ↔ 연천 북부 연장선 및 경부선/광명셔틀/서동탄지선 분기 정상화
  10. **🔄 동일 호선 지선/분기역 필수 계통 환승 처리**: 구일역(경인선) ↔ 가산디지털단지역(경부선) 간 구로역 필수 환승 강제 적용 및 구로역 실시간 환승 열차 도착 시간 표출
