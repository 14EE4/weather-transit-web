## 📌 개요
본 문서는 Weather & Transit Web 시스템에서 사용하는 **외부 공공 OpenAPI(기상청, 서울시 버스, 서울시 지하철, 따릉이)**와 **백엔드 AI 추론 엔진(FastAPI + ONNX Runtime)**의 정상 연동 여부를 터미널 환경에서 사전에 점검하고 디버깅하기 위한 테스트 가이드입니다.

## 1. 외부 공공 OpenAPI 연동 테스트 (`tests/test_api.py`)

기상청 초단기실황, 서울시 버스 도착 정보(전체 노선 및 저상버스), 서울시 지하철 실시간 도착 정보 API가 유효한 키로 정상 통신하는지 점검합니다.

### 실행 방법
```bash
# 가상환경 활성화 후 실행
python tests/test_api.py
```

## 2. 백엔드 AI 추론 통합 테스트 (`tests/test_inference.py`)

32차원 ONNX 모델 3종(따릉이/버스/지하철) 인메모리 세션 웜업, 피처 정합성, 기상 시나리오별 모달 시프트 및 추론 응답 지연(Latency SLA)을 종합 검증합니다.

### 실행 방법
```bash
python tests/test_inference.py
```

### 주요 검증 항목
1. **ONNX 모델 세션 웜업**: `models/*.onnx` 3개 수단 모델 인메모리 로딩 및 더미 입력 통과 여부
2. **32차원 피처 벡터 정합성**: 캘린더(8D), 기상(8D), 공간/인프라(5D), 시계열 통계(11D) 벡터 생성 무결성
3. **모달 시프트(Modal Shift) 반응성**: 맑은 날(0mm) 대비 폭우(10mm) 시 따릉이 이용 급감 및 지하철 우선 추천 점수 역전 검증
4. **추론 속도 SLA 벤치마크**: 10회 연속 호출 기준 평균 1~3ms (SLA 15ms 이하) 준수 여부

## 3. 공공 API 장애 및 오류 해결 가이드 (Troubleshooting)

| 증상 | 원인 | 조치 방안 |
| :--- | :--- | :--- |
| `KMA_APIHUB_KEY` 401/403 오류 | 인증키 만료 또는 IP 미등록 | [기상청 API허브](https://apihub.kma.go.kr)에서 단기예보 키 재발급 및 `.env` 반영 |
| 서울 버스 `LIMITED_NUMBER_OF_SERVICE...` | 일일 호출 트래픽 초과 | 공공데이터포털 개발계정 일일 한도(1,000~10,000건) 확인 또는 운영계정 신청 |
| 서울 버스 `SERVICE_ACCESS_DENIED_ERROR` | 활용신청 미승인 서비스 호출 | 버스 5종(도착·정류소·위치·노선·환승) 활용신청 전수 승인 여부 확인 |
| 지하철 `INFO-200` 오류 | 운행 종료 심야 시간대 또는 역사명 오타 | 01시~05시 심야 시간대 여부 확인 (역명 뒤 '역' 제외하고 검색: '강남' (O), '강남역' (X)) |
