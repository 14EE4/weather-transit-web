> **적용 대상**: 다년도(2023~2025) 통합 전처리 데이터 및 서빙/추론 피처 생성 파이프라인

## 1. 개요 및 변경 배경

기존 v2 파이프라인은 2025년 단년도 33개 컬럼의 CSV 데이터를 기반으로 학습 및 서빙을 수행하였습니다.  
그러나 **추론 시 실제 입력되지 않는 풍향 관련 컬럼**과 **타깃으로 사용되지 않는 지하철 하차 컬럼**이 원천 데이터에 잔존하여 혼선을 유발했습니다.

2026-10-29 파이프라인 개편을 통해 다음 개선을 완료하였습니다:
1. **불필요한 5개 컬럼 영구 삭제**:
   - `풍향`, `풍향_결측`, `풍향0_풍속양수` (모델 미반영 기상 열)
   - `지하철_하차`, `지하철_하차_결측` (서빙 타깃 미사용 교통 열)
2. **28열 표준 포맷 확립**: 33열에서 5열을 제거한 순수 28개 열로 정규화.
3. **다년도(2023~2025) 데이터 통합**:
   - `2023_train.csv` (209,875행)
   - `2024_train.csv` (209,875행)
   - `2025_test.csv` (209,875행)
   - **총 데이터 규모**: 629,625행 (약 63만 건)

## 3. 결측치 및 도메인 정제 규칙

1. **지하철 심야 운휴 시간대 (01시 ~ 05시)**:
   - 지하철은 해당 시간에 운행하지 않으므로 결측이 아닌 **구조적 0 (Structural Zero)** 으로 처리합니다.
   - `df.loc[df["시간"].isin([1, 2, 3, 4, 5]), ["지하철_승차"]] = 0.0`
2. **강수량 무강우 결측치**:
   - `df["강수량(mm)"] = df["강수량(mm)"].fillna(0.0)`
3. **기상 관측치 결측 보간**:
   - 기온, 풍속, 습도는 자치구별 시계열 전후값 선형 보간(`interpolate(method="time")`) 및 전체 평균으로 채웁니다.
4. **교통량 음수 방지**:
   - 교통 관측값 및 모델 예측값은 물리적으로 음수가 불가하므로 `clip(lower=0.0)` 처리합니다.

## 4. 다년도 시계열 분할 (Temporal Split) 규약

데이터 누수(Data Leakage)를 방지하기 위해 날짜 기준 순차 분할을 적용합니다:

```text
[ 2023-01-01 ~ 2024-09-30 ] : Train      (약 38.5만 행) - 다년도 패턴 학습
[ 2024-10-01 ~ 2024-12-31 ] : Validation (약  5.4만 행) - 하이퍼파라미터 튜닝 및 Early Stopping
[ 2025-01-01 ~ 2025-12-31 ] : Test       (약 21.0만 행) - 미래 1년치 완전 일반화 검증
```

## 5. 모델 입력 피처(32차원) 매핑 규약

서빙 코드([`main.py`](../main.py))와 모델([`models/*.onnx`](../models/))은 위 28열 데이터로부터 다음의 **32차원 실수 벡터**를 생성하여 입력으로 사용합니다.

```
 인덱스   피처명                      생성 공식 / 출처
────────────────────────────────────────────────────────────────────────────
 [0..3]  month_sin, month_cos       sin/cos(2π * month / 12)
         hour_sin, hour_cos         sin/cos(2π * hour / 24)
 [4..7]  dayofweek                  0(월) ~ 6(일)
         is_weekend                 1 if dayofweek in [5, 6] else 0
         is_holiday                 대한민국 관공서 공휴일 캘린더 (19일)
         is_rush_hour               1 if hour in [7, 8, 9, 17, 18, 19, 20] else 0
────────────────────────────────────────────────────────────────────────────
 [8..15] temperature                기온(°C)
         wind_speed                 풍속(m/s)
         humidity                   습도(%)
         precipitation              강수량(mm)
         is_raining                 1 if precipitation > 0 else 0
         rain_intensity             강우강도_범주 (0~3)
         sensible_temp              체감온도(°C)
         discomfort_index           불쾌지수
────────────────────────────────────────────────────────────────────────────
 [16..20] district_code             자치구 코드 (1~25, 강남=1 ... 중랑=25)
          district_subway_stations  자치구 내 지하철역 수 (예: 강남 18)
          district_bus_stops        자치구 내 버스정류소 수 (예: 강남 503)
          district_bike_racks       자치구 내 따릉이 거치대 수 (예: 강남 161)
          commercial_density        자치구 상업밀도 지수
────────────────────────────────────────────────────────────────────────────
 [21..26] 따릉이_대여_lag_1h          직전 1시간 실측 교통량
          버스_승차_lag_1h
          지하철_승차_lag_1h
          따릉이_대여_roll_3h         직전 3시간 이동평균
          버스_승차_roll_3h
          지하철_승차_roll_3h
 [27..29] same_day_last_week_bike   7일 전 동일 요일·동일 시각 대여량
          same_day_last_week_bus    7일 전 동일 요일·동일 시각 승차량
          same_day_last_week_sub    7일 전 동일 요일·동일 시각 승차량
 [30..31] temp_diff_1h              1시간 전 대비 기온 변화량 (현재기온 - 직전기온)
          rain_diff_1h              1시간 전 대비 강수량 변화량
```
