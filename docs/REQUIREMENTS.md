# [요구사항 명세서] 기상 및 교통 데이터 기반 대중교통 수요 예측 웹 시스템

## 1. 프로젝트 개요

* **시스템명**: 기상 및 대중교통 데이터 기반 실시간/시계열 수요 예측 웹 플랫폼
* **개발 목표**: 기상 상태(강수, 기온 등) 및 시간대별 대중교통(버스, 지하철) 데이터를 수집·가공하고, 시계열 머신러닝 예측 모델을 통해 미래 수요 및 혼잡도를 산출하여 웹 기반 대시보드(MapLibre GL JS)로 시각화함.

---

## 2. 시스템 아키텍처 및 기술 스택

* **Frontend**: MapLibre GL JS, OpenStreetMap, Chart.js / 시각화 라이브러리, HTML5/CSS/JavaScript
* **Backend**: Python (FastAPI 또는 데이터 파이프라인 스크립트), RESTful API 엔드포인트
* **AI / ML**: Python 시계열 예측 모델, Scikit-learn / PyTorch / LightGBM 등
* **Data Sources**:
* 기상청 API허브: 초단기실황, 단기예보, 관측 데이터
* 공공데이터포털 / 서울 열린데이터광장: 버스 도착 및 위치 정보, 지하철 실시간 도착 및 승하차 통계 데이터



---

## 3. 기능 요구사항 (Functional Requirements)

### FR-01: 데이터 파이프라인 및 연동

* **FR-01-1 (외부 API 실시간 연동)**: 기상청 초단기실황 API와 서울시 대중교통(버스/지하철) 실시간 도착 정보를 백엔드에서 주기적으로 호출·수신해야 한다.
* **FR-01-2 (시공간 데이터 정제 및 동기화)**: 수집된 이종(Heterogeneous) 데이터를 시간(정시 단위) 및 공간(좌표, 정류장/역 ID, 최근접 기상 격자) 기준으로 병합·정렬해야 한다.
* **FR-01-3 (결측치 및 이상치 필터링)**: 수집 데이터의 결측치, 통신 지연 값, 노이즈를 사전에 보정하여 모델 입력 규격에 맞게 변환해야 한다.

### FR-02: AI 수요 및 혼잡도 예측 엔진

* **FR-02-1 (시계열 모델 추론)**: 입력된 기상 요인(강수량, 기온 등)과 과거 이용 패턴을 기반으로 목표 시점의 지역/노선별 수요 및 혼잡도를 추론해야 한다.
* **FR-02-2 (예측 결과 전달)**: 추론된 수요 예측 수치와 혼잡도 레벨을 프론트엔드가 즉각 조회할 수 있도록 JSON 형식의 데이터 구조로 가공하여 반환해야 한다.

### FR-03: 프론트엔드 대시보드 및 지도 시각화

* **FR-03-1 (인터랙티브 웹 지도)**: MapLibre GL JS와 OpenStreetMap 타일을 연동하여 부드러운 이동, 줌, 중심점 이동(`flyTo`) 기능을 지원해야 한다.
* **FR-03-2 (교통 거점 마커 표출)**: 주요 정류소 및 지하철역 좌표를 지도 위에 마커로 렌더링하고, 클릭 시 해당 지점의 실시간 정보 팝업을 제공해야 한다.
* **FR-03-3 (수요/혼잡도 시각화)**: AI 예측 결과에 따라 정류장/역 단위의 혼잡도를 단계별 색상(히트맵 또는 컬러 마커)으로 표현해야 한다.
* **FR-03-4 (시계열 변화 차트)**: 기상 악화 시나리오 및 시간 경과에 따른 대중교통 수요 변동 추이를 그래프 인터페이스로 확인할 수 있어야 한다.

---

## 4. 비기능 요구사항 (Non-Functional Requirements)

* **NFR-01 (보안 및 환경 설정 분리)**: 모든 외부 API 인증키는 `.env` 환경 변수 파일에 분리 보관하며, Git 추적 대상(`.gitignore`)에서 철저히 배제한다.
* **NFR-02 (API 호출 최적화)**: 외부 공공 API의 일일 호출 한도(Quota) 초과를 방지하기 위해 캐싱 메커니즘을 적용한다.
* **NFR-03 (개발 환경 일관성)**: 파이썬 가상환경(`venv`)과 명확한 의존성 정의(`requirements.txt`)를 통해 환경 간 종속성 충돌을 방지한다.
* **NFR-04 (반응형 렌더링)**: 지도 조작 및 데이터 조회 요청 시 사용자가 체감하는 지연 시간을 최소화하도록 가벼운 GeoJSON 레이어를 구성한다.
