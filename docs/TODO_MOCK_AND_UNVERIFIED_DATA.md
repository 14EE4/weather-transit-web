## 2. 백엔드 AI 추론 피처 및 미검증 수치 (Backend & ML Features)

### 2.1 시계열 래그(Lag) 및 이동 통계 피처의 정적 대체
- **위치**: `main.py` (`build_feature_vector`, L357~373)
- **현황**: 32차원 피처 중 11차원에 해당하는 시계열 피처가 실시간 이력 DB 부재로 연간 평균값(`DISTRICT_STATS["mean"]`)으로 고정 대입됨:
  - `bike_lag_1h`, `bus_lag_1h`, `subway_lag_1h`
  - `bike_roll_mean_3h`, `bus_roll_mean_3h`, `subway_roll_mean_3h`
  - `same_day_last_week_bike`, `same_day_last_week_bus`, `same_day_last_week_sub`
  - `temp_diff_1h = 0.0`, `rain_diff_1h = 0.0`
- **검증 필요 사항**:
  - 래그 변수가 평균값으로 고정되면 모델이 급격한 날씨 변화(돌발 소나기 등) 직후의 시계열 관성을 정밀하게 반영하지 못함.
- **[TODO]**:
  - [ ] Redis 또는 인메모리 SQLite에 최근 3시간 교통량/기상 관측치 캐시 테이블 구축
  - [ ] 직전 1시간 실제 승하차량 및 직전 기온/강수량과의 차분값(`diff_1h`) 동적 산출 파이프라인 연결

### 2.2 25개 자치구 인프라 통계치 (`DISTRICT_INFRA`)
- **위치**: `main.py` (L65~91)
- **현황**: 자치구별 지하철 역사수(`subway_stations`), 버스 정류소수(`bus_stops`), 따릉이 거치대수(`bike_racks`), 상업 밀도(`commercial_density`)가 정적 딕셔너리로 기입됨.
- **검증 필요 사항**:

- **[TODO]**:

### 2.3 MCDA 추천 스코어링 공식의 휴리스틱 가중치
- **위치**: `main.py` (`evaluate_subway`, `evaluate_bus`, `evaluate_bike`, L429~525)
- **현황**:
  - **지하철**: `100 - (0.0[날씨] + 2.0[지연] + 0.40 * crowd)`
  - **버스**: `100 - (min(30, 3.5*rain + 5) + (15 + 2.5*rain) + 0.35 * crowd)`
  - **따릉이**: `100 - (min(80, 25*rain + 15) + 10 + 0.15 * crowd)`
- **검증 필요 사항**:
  - 강수량 1mm당 버스 지연 리스크 2.5점 감점, 따릉이 강수 감점 계수 25 등은 경험적(Rule-based) 가중치임.
  - 실제 강우 시 교통카드 실측 모달 시프트(이용객 전환율) 데이터와 비교하여 계수 캘리브레이션(Calibration) 필요.
